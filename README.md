# 无限基因法则

## 项目简介

这是一个基于虚幻引擎的多人玩法项目。

## 软件架构

项目采用面向虚幻引擎多人运行的分层架构：引擎入口负责生命周期接入，`GameFlow` 负责流程编排，领域服务负责服务端权威规则，`Common` 提供双端共享契约，UI 和场景通过公开接口与事件协作。

详细的目录规划、三人职责、复制与存档规则、资产管理、Git 流程和迁移计划见：[项目架构与多人协作规范](docs/项目架构与多人协作规范.md)。

## 安装教程

1. 使用团队约定的虚幻编辑器版本打开项目。
2. 按 `setup.bat` 和 `workspace.code-workspace` 中的本地开发约定配置环境。
3. 在 PIE 中至少启动一次服务端和客户端，确认脚本、地图和 UI 资源均可加载。

## 使用说明

1. Lua 事件、全局变量和代码规范见 `docs/` 目录。
2. 新功能开发前先阅读[项目架构与多人协作规范](docs/项目架构与多人协作规范.md)，确定目录、主责人和接口。
3. 涉及事件、复制字段、存档或资产路径的改动，需在同一 PR 中更新对应文档。

## 参与贡献

1. Fork 本仓库。
2. 新建 `feature/<领域>-<简述>` 分支。
3. 提交代码并完成 PIE 验证。
4. 新建 Pull Request，填写变更范围和验证结果。
